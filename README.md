# ☕ Café Cerrado

> Café especial com sabor de Cerrado.

O **Café Cerrado** é um projeto acadêmico de desenvolvimento web que simula o site de uma cafeteria fictícia inspirada na cultura do café e nos sabores do Cerrado brasileiro. O projeto apresenta uma interface moderna, acolhedora e responsiva, reunindo informações sobre produtos, destaques da semana, acessibilidade e contato com os clientes.

## 📖 Sobre o projeto

O Café Cerrado foi desenvolvido com o objetivo de aplicar conhecimentos de desenvolvimento web front-end, utilizando HTML, CSS e JavaScript para criar uma página funcional, interativa e organizada.

A proposta é representar uma cafeteria que valoriza cafés especiais, produtos artesanais, sustentabilidade e a identidade regional do Cerrado.

O site possui layout adaptável, navegação por seções, cardápio interativo, carrossel de destaques, formulário de contato simulado e ferramentas de acessibilidade.

---

## ✨ Funcionalidades

### 🏠 Página inicial
- Apresentação da cafeteria.
- Identidade visual baseada em tons de café e elementos naturais.
- Navegação entre as principais seções do site.
- Botões de acesso ao cardápio e contato.

### ☕ Cardápio interativo
- Exibição de produtos da cafeteria.
- Categorias de produtos:
  - Cafés
  - Doces
  - Salgados
- Filtro por categoria.
- Pesquisa de produtos por nome ou descrição.
- Exibição de descrição e preço dos produtos.

### 🎯 Destaques da semana
- Carrossel de conteúdos promocionais e informativos.
- Navegação entre slides.
- Botões de anterior e próximo.
- Indicadores de posição.
- Reprodução automática.
- Opção de pausar e retomar a rotação.

### ℹ️ Seção “Saiba mais”
Apresentação de informações relacionadas a:

- Origem dos cafés.
- Processo de torra.
- Sustentabilidade.

### 📩 Formulário de contato
- Campo para nome.
- Campo para e-mail.
- Seleção de assunto.
- Campo para mensagem.
- Validação dos campos preenchidos.
- Mensagem de retorno ao usuário.

### 🔐 Área de login demonstrativa
- Modal de login.
- Campo de e-mail.
- Campo de senha.
- Validação básica dos dados.
- Mensagem de retorno para simulação de autenticação.

### ♿ Recursos de acessibilidade
- Atalho para pular diretamente ao conteúdo.
- Aumento e diminuição do tamanho da fonte.
- Alternância entre modo claro e escuro.
- Opção de alto contraste.
- Opção para reduzir animações.
- Uso de etiquetas e atributos acessíveis.
- Navegação com teclado e indicadores de foco.

## ⚠️ Observações

Este projeto possui caráter acadêmico e demonstrativo.

- A cafeteria Café Cerrado é fictícia.
- Os preços apresentados são ilustrativos.
- O formulário de contato realiza validação e simulação de envio, não enviando mensagens para um servidor real.
- O sistema de login é demonstrativo e não possui autenticação real.
- Não há integração com banco de dados.
- Os dados não são enviados para um backend.
